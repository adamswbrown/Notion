# Productivity Templates

Three operational thinking frameworks built as Notion templates.

## Templates

### 1. Customer Engagement Control Tower
Post-sale execution OS for consultants. Tracks the full lifecycle from sales call through delivery, follow-ups, and expansion.

**Target:** Technical consultants, MSP engineers, cloud architects, freelance advisors
**Price:** £19-£39
**Positioning:** "Run consulting engagements like a product team instead of a to-do list."

### 2. Decision Engine Canvas
Reusable visual framework for presenting technical decisions to stakeholders. Not a slide deck - a reasoning system.

**Target:** Technical leads, architects, engineering managers
**Price:** £12-£25
**Positioning:** "Make stakeholders agree with you before you finish the meeting."

### 3. Personal Operating System
Mental load management system designed around activation difficulty, cognitive load, and state transitions.

**Target:** Neurodivergent professionals, developers, engineers, knowledge workers
**Price:** £29-£59
**Positioning:** "A productivity system designed for how your brain actually executes tasks."

## Repository Structure

```
templates/
  01-customer-engagement-control-tower/
    schema.md          # Database definitions, properties, relations
    automations.md     # Automation rules and triggers
    views.md           # View configurations and filters
  02-decision-engine-canvas/
    schema.md          # Database definitions and calculator logic
    canvas-template.md # Section framework and variations
  03-personal-operating-system/
    schema.md          # Database definitions, properties, relations
    automations.md     # Automation rules and triggers
    views.md           # View configurations and filters
```

Each template directory contains the complete specification needed to build the template in Notion. Schemas define every database, property, relation, and formula. Automations define trigger-based behaviours. Views define the default board/table/calendar configurations.
